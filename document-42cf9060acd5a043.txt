🧠 STEP 5: FLOW (END-TO-END EXECUTION)


---

🔥 Full Flow

1. Vendor created
2. SKU ready
3. PO comes from SAP
4. Vendor submits ASN
5. Slot booked
6. Truck arrives → Gate Entry
7. Dock assigned
8. QC scanning happens
9. Validation runs
10. If OK → GRN created
11. GRN sent to SAP
12. Inventory updated


---

🧠 STEP 6: EVENT-DRIVEN THINKING (VERY IMPORTANT)

Instead of direct calls, use events


---

Example:

ASN_CREATED → trigger slot booking
TRUCK_ARRIVED → start timer
QC_COMPLETED → trigger validation
VALIDATION_SUCCESS → create GRN
GRN_CREATED → update inventory + send SAP


---

👉 Use:

Kafka / PubSub / Redis Queue
